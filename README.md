# ONE1TOUCH APP для Windows

Официальное **desktop-приложение ONE1TOUCH** для Windows 10 и 11.

**Текущая версия:** [1.0.2](https://github.com/ONE1TOUCH-App/one1touch-windows-app/releases/latest) · **Платформы:** x64 (рекомендуется) и ARM64

## Скачать

Актуальные установщики — в **[GitHub Releases](https://github.com/ONE1TOUCH-App/one1touch-windows-app/releases/latest)**.

| Файл | Для кого |
|------|----------|
| `ONE1TOUCH-APP-Setup-1.0.2-x64-win10-11.exe` | Windows 10/11, Intel/AMD (x64) — **рекомендуется** |
| `ONE1TOUCH-APP-Setup-1.0.2-arm64-win10-11.exe` | Windows 10/11 на ARM-процессоре |

Обновление с **1.0.1** (`ONE1TOUCH VPN`): меню трея или **Параметры** → «Проверить обновления», либо установите новый установщик поверх старой версии.

---

## Быстрый старт

1. Скачайте установщик **x64** (или **arm64** на ARM-устройстве).
2. Установите и запустите **ONE1TOUCH APP**.
3. Войдите в аккаунт и выберите подписку → **Подключить**.
4. При первом подключении Windows может один раз запросить права администратора (TUN).

Логи: `%APPDATA%\ONE1TOUCH APP\logs\client.log`
