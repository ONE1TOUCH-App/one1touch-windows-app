# ONE1TOUCH APP для Windows

Официальное **desktop-приложение ONE1TOUCH** для Windows 10 и 11.

**Текущая версия:**
[1.0.5](https://github.com/ONE1TOUCH-App/one1touch-windows-app/releases/latest)
**Платформы:** x64 (рекомендуется) и ARM64

---

## Скачать

Актуальные установщики — в **[GitHub Releases](https://github.com/ONE1TOUCH-App/one1touch-windows-app/releases/latest)**.

| Файл | Для кого |
|------|----------|
| `ONE1TOUCH-APP-Setup-1.0.5-x64-win10-11.exe` | Windows 10/11, Intel/AMD (x64) — **рекомендуется** |
| `ONE1TOUCH-APP-Setup-1.0.5-arm64-win10-11.exe` | Windows 10/11 на ARM-процессоре |

Обновление с **1.0.4**: меню трея или **Параметры** → «Проверить обновления», либо установите новый установщик поверх предыдущей версии.

---

## Быстрый старт

1. Скачайте установщик **x64** (или **arm64** на ARM-устройстве).
2. Установите и запустите **ONE1TOUCH APP**.
3. Войдите в аккаунт и следуйте подсказкам в приложении.
4. При первом запуске некоторых функций Windows может один раз запросить права администратора.

---

## Что нового в 1.0.5

- **Защита от утечки** — блокировка интернета при неожиданном обрыве VPN (включается в настройках туннеля).
- **Мультиподписка** — несколько серверов в одной подписке и общая ссылка для импорта.
- Вкладки **«Подписки»** и **«Ключи»** в личном кабинете и при выборе VPN.
- **Сборщик подписки** — объединение ключей в одну подписку.
- Актуальный **статус серверов** и улучшенный личный кабинет в desktop-приложении.
