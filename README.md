# ONE1TOUCH APP для Windows

Официальное **desktop-приложение ONE1TOUCH** для Windows 10 и 11.

**Текущая версия:**
[1.0.6](https://github.com/ONE1TOUCH-App/one1touch-windows-app/releases/latest)
**Платформы:** x64 (рекомендуется) и ARM64

---

## Скачать

Актуальные установщики — в **[GitHub Releases](https://github.com/ONE1TOUCH-App/one1touch-windows-app/releases/latest)**.

| Файл | Для кого |
|------|----------|
| `ONE1TOUCH-APP-Setup-1.0.6-x64-win10-11.exe` | Windows 10/11, Intel/AMD (x64) — **рекомендуется** |
| `ONE1TOUCH-APP-Setup-1.0.6-arm64-win10-11.exe` | Windows 10/11 на ARM-процессоре |

Обновление с **1.0.5**: меню трея или **Параметры** → «Проверить обновления», либо установите новый установщик поверх предыдущей версии.

---

## Быстрый старт

1. Скачайте установщик **x64** (или **arm64** на ARM-устройстве).
2. Установите и запустите **ONE1TOUCH APP**.
3. Войдите в аккаунт и следуйте подсказкам в приложении.
4. При первом запуске некоторых функций Windows может один раз запросить права администратора.

---

## Что нового в 1.0.6

- **Проксирование по приложениям** — в **Параметры** режим «Только выбранные»: подключение только для указанных программ (имя из диспетчера задач).
- **Автопереключение подписок** — при сбое подключения клиент пробует следующую подписку или сохранённый ключ.
- **Продление мультиподписки** — единый выбор подписки для продления в личном кабинете.
- **Обновлённый интерфейс** — единые модалки кабинета, карточки серверов, инструкции со ссылками на Releases.
- **Защита от утечки**, мультиподписка, сборщик ключей, автообновление — сохранены из 1.0.5.
