# ONE1TOUCH VPN — загрузки для Windows

Официальные **установщики** десктоп-клиента ONE1TOUCH для Windows 10/11.

Исходный код здесь **не публикуется** — только файлы релизов для скачивания и обновления приложения.

## Скачать

**[Releases](https://github.com/ONE1TOUCH-App/one1touch-windows-app/releases)**

| Файл | Для кого |
|------|----------|
| `ONE1TOUCH-VPN-Setup-*-x64-win10-11.exe` | Windows 10/11, Intel/AMD (основной) |
| `ONE1TOUCH-VPN-Setup-*-arm64-win10-11.exe` | ARM64 |

## Установка

1. Скачайте **x64** установщик (или **arm64** на ARM).
2. Установите, войдите в аккаунт, подключите VPN.
3. При первом соединении Windows может запросить Права Администратора — один раз.
